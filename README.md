## Featured project

### [Windows Server Home Lab](https://github.com/MathewsSolutions/windows-server-home-lab)
A working Windows domain built from scratch on a repurposed Dell OptiPlex 7020 (i7, 32 GB RAM).

- Windows Server 2025 running directly on the hardware, with Hyper-V hosting the lab VMs
- Isolated lab network (192.168.100.0/24) using a Hyper-V internal switch and Windows NAT
- Domain controller with a new Active Directory forest, integrated DNS and DNS forwarders
- AD-authorized DHCP scope, with a Windows 11 Enterprise client joined to the domain
- Most configuration done in PowerShell, with Hyper-V checkpoints before major changes
- Troubleshot VM boot failures, a misleading NAT error and an unsupported Wi-Fi driver on Windows Server

**In progress:** users, groups and OUs · Group Policy · file shares and permissions
