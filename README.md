## Featured project

### [Windows Server Home Lab](https://github.com/MathewsSolutions/windows-server-home-lab)

A working Windows domain built from scratch on a repurposed Dell OptiPlex 7020 (i7, 32 GB RAM), then used to practice real help desk work.

**Infrastructure**
- Windows Server 2025 running directly on the hardware, with Hyper-V hosting the lab VMs
- Isolated lab network (192.168.100.0/24) using a Hyper-V internal switch and Windows NAT
- Domain controller with a new Active Directory forest, integrated DNS and DNS forwarders
- AD-authorized DHCP scope, with a Windows 11 Enterprise client joined to the domain

**Help desk practice**
- Built an OU structure with users and security groups
- Worked tickets for new hires, identity-verified password resets, account lockouts and offboarding
- Granted folder access through group-based NTFS and share permissions, and mapped network drives

**Security**
- Applied Microsoft's Windows Server 2025 security baseline to the host and domain controller
- Enabled Secure Boot and memory integrity on the host, then verified every service still worked

**Troubleshooting**
- Fixed an unsupported Wi-Fi driver on Windows Server, cleared a locked BIOS password with the motherboard jumper, and resolved permission errors after hardening

**Next:** Group Policy · Remote Desktop for standard users · a firewall VM
